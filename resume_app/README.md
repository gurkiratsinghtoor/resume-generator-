# Resume Preparation & Checking System

## Run
    pip install -r requirements.txt
    streamlit run app.py

## Features
- Builder: fill a form, preview, download as .txt / .docx
- Checker: upload PDF/DOCX/TXT or paste text -> score out of 100
  (contact info, sections, length, action verbs, numbers, weak phrases)
- Job description keyword match with missing keywords
